# Security

Detour runs on the machine it is on. It changes Windows settings you approve,
one at a time, and logs each one so it can be undone. It never patches the
game, its anti-cheat or any other process.

If you find a way to make Detour read or write outside its own folder and
the settings it owns, or to make it touch a process it shouldn't, report it
privately through GitHub's **Report a vulnerability** button instead of a
public issue.
